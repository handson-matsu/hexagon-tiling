# 正六角形タイリング確認アプリ

ブラウザだけで動作する、正六角形の紙の分割・表裏・敷き詰めを確認するアプリです。依存パッケージやビルドは不要です。

## 起動

```sh
python3 -m http.server 8016 --bind 127.0.0.1
```

http://127.0.0.1:8016/ を開いてください。Node.js がある環境では `npm start` も利用できます。

## 操作と仕様

- 辺0は上辺。時計回りに0〜5を割り当て、回転・鏡映で同値な配置をまとめた固定5タイプから選びます。完成タイルの外側に「辺番号: ペア名」を表示します。
- 各組を「半分にする」と、2辺間のペアを解除し、各辺内の2枚を新しいペアにします。6/8/10/12ピース、3/4/5/6ペアに対応します。
- マーク・色は各ペアで設定し、表裏は切断前の位置で識別する各物理ピースで指定します。色は一致判定に影響しません。
- 半分ピースは30°–60°–90°の三角形です。裏返すと左右の形が入れ替わるため、形が合うスロットへ移動します。左右の枚数が合わない設定も選択できますが、その間は組立不可として描画・PNG保存を停止します。実物の紙で成立しない重なりや変形はしません。
- 分割を戻すと、時計回りで先の区間の表裏を引き継ぎます。ペア配置を変えると分割は解除されます。同じメンバーのペアのマーク・色は保持されます。
- タイルを選び、再クリックすると60°回転します。反転はそのタイルのローカル軸に対する鏡映です。選択タイルの反転・回転は設定元タイルの表裏とは独立して重ねて適用されます。
- 中央の手は共通版と同じパスを使い、完成タイルに後から描いた目印として扱います。
- 20枚のハニカムにある共有43辺を判定します。辺の位置、区間、マークの種類、左右、向き、鏡映後の形状を比較します。外周は対象外です。
- PNGには現在の分割線・表裏色・手・警告表示を反映し、辺ラベル・選択枠は除去します。
- GASへ `app=hexagon-tiling` のGETを文書初期化時に1回だけ送信します。失敗時は再送せず操作を継続します。

## テスト

```sh
npm test
```

`tests/geometry.test.js` と `tests/access-counter.test.js` が、全15配置×8分割（内部幾何学）と5タイプの対称性分類、面積、ペア構成、変換の恒等式、物理的な組立、共有辺判定、共通GAS設定、1回送信、再読み込み、通信失敗を検証します。

ローカルサーバーで `/tests/browser.html` を開くと、DOM操作、固定5タイプ、5タイプ×8分割のピース数切替、表裏と交換、6回回転・2回反転、手の色、警告切替、アクセス送信、2種類のPNG生成を自動確認します。このページ内のアプリはGAS通信をモックし、PNGテストはテスト画像をダウンロードします。

開発時確認: 内蔵Node実行環境で自動テスト19件のアサーションが成功（シェルにnode/npmがないため、テスト登録部分のみローカル実行用に置き換えて検証）、ローカルブラウザ自動テスト19件成功。通常画面もブラウザで表示確認済み。GAS側の実際の記録保存は不透明な no-cors レスポンスでは確認できないため、管理側での確認が必要です。

既存の `tiling-checker` と `triangle-tiling` は参照のみで、変更していません。

ペア配置の代表元は `src/pairing-types.js` に定義しています。全15マッチングをプログラムで列挙し、回転6通りおよび回転・鏡映12通りの作用による同値類がともに5個になることをテストします。タイプ番号は代表元に固定されています。タイプ3の配置は隣・対・隣です。

マークは辺（分割時は各半辺区間）の中点を基準に従来の1.4倍に拡大しています。`tests/mark-size.test.js` で拡大率、切断軸、全6マークのピース内包含と隣接ピースへの余白、半分区間での組み合わせを検証します。ブラウザテストでは6/8/10/12ピースの両画面と8種類のPNG生成を確認します。

アクセス記録の追加確認: `/tests/access-browser.html` は成功・非同期失敗・同期失敗の3条件で計15件を検証します。初回GET1回、全操作中の追加送信なし、実際のiframe再読み込みで新規GET1回、通信エラーの隔離、実保存ボタン経由のタイル・全体PNG生成を確認します。テスト中のGAS通信とダウンロードリンク起動だけを置換し、PNGのBlobは実際に生成して形式を検証します。2026年11月7日の確認でアクセス専用自動テスト5件、ブラウザ統合テスト15件が成功しました。アクセス記録のアプリ本体コードは既存2アプリと識別子以外が一致しており、変更していません。GAS管理画面・保存先への接続がないため、実際の保存結果は未確認です。
